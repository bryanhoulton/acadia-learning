# WWW

A Vite + React + TypeScript + Tailwind CSS project.

## Features

- **Vite** - Fast build tool and dev server
- **React 19** - Latest React with TypeScript
- **Tailwind CSS v4** - Utility-first CSS framework with custom design tokens
- **Custom Design System** - Copied from the portal project with:
  - Custom color palette (primary, secondary, neutral, success, error, warning, info)
  - Google Fonts integration (PT Serif, Alegreya Sans SC, Lato)
  - Custom CSS variables and theme configuration

## Getting Started

```bash
# Install dependencies
yarn

# Start development server
yarn dev
# or
yarn start

# Build for production
yarn build

# Preview production build
yarn preview

# Lint code
yarn lint
```

## Design System

The project includes a comprehensive design system with:

- **Colors**: Primary (#00a071), Secondary (#1f75fe), and semantic colors
- **Typography**: PT Serif for headings, system fonts for body text
- **Spacing**: Tailwind's default spacing scale
- **Components**: Ready for custom component development

## Development

The project is configured with:

- TypeScript for type safety
- ESLint for code quality
- Tailwind CSS v4 with custom theme configuration
- Hot module replacement (HMR) for fast development

Visit `http://localhost:5173` when running the dev server.
